# DooList

O DooList é um projeto simples de front-end para praticar HTML, CSS e JavaScript, com a proposta de organizar tarefas.

Atualmente, o projeto contém uma página inicial com navegação responsiva. Em telas menores, o menu pode ser aberto e fechado pelo botão, pelos links ou pelo overlay. O gerenciamento de tarefas ainda não está implementado.

## Como executar

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências.

## Estrutura

- `index.html` — página inicial e estrutura da navegação.
- `recursos/css/style.css` — estilos e layout responsivo.
- `recursos/js/menu.js` — comportamento do menu mobile.
- `recursos/imagens/` — imagens utilizadas no projeto.
